# gas-ai-inquiry-classifier（サンプル）

Google Apps Script × 生成AI の連携サンプルです。スプレッドシートに集まったお問い合わせ文を、AIで自動で「分類」と「要約」に振り分けてシートに書き戻します。

## これは何か

- 「お問い合わせ」シートの B列（本文）を読み取り、C列に分類（料金／使い方／不具合／その他）、D列に40文字以内の要約を書き出すApps Script
- メニュー「AI処理」から手動実行する形式（トリガーで定期実行も可能）
- APIキーはスクリプトプロパティで管理し、コードに直書きしない

## 位置づけ

動作イメージを示すためのデモ用サンプルコードです。実案件の納品物ではありません。AI APIの呼び出し部分は OpenAI API を想定していますが、Gemini API 等への差し替えも容易な構成にしています。

## こういう相談に応用できます

- 問い合わせ・申し込みフォームの一次振り分け
- アンケート自由記述の分類と要約
- 日報・議事録の要約をシートに自動記録
